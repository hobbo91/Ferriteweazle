usage: gw pin get [options] pin

Change the setting of a user-modifiable interface pin.

positional arguments:
  pin              pin number

options:
  -h, --help       show this help message and exit
  --device DEVICE  device name (COM/serial port)
  --drive DRIVE    drive to read (default: A)

DRIVE: Drive (and bus) identifier:
  0 | 1 | 2 | 3       :: Shugart bus unit
  A | B               :: IBM/PC bus unit
