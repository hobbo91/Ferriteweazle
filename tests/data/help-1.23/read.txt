usage: gw read [options] file

Read a disk to the specified image file.

positional arguments:
  file                  output filename

options:
  -h, --help            show this help message and exit
  --device DEVICE       device name (COM/serial port)
  --drive DRIVE         drive to read (default: A)
  --diskdefs DISKDEFS   disk definitions file
  --format FORMAT       disk format (output is converted unless --raw)
  --revs N              number of revolutions to read per track
  --tracks TSPEC        which tracks to read
  --raw                 output raw stream (--format verifies only)
  --fake-index SPEED    fake index pulses at SPEED
  --hard-sectors        read from a hard-sectored disk
  --adjust-speed SPEED  scale track data to effective drive SPEED
  --retries N           number of retries per seek-retry (default: 3)
  --seek-retries N      number of seek retries (default: 0)
  -n, --no-clobber      do not overwrite an existing file
  --pll PLLSPEC         manual PLL parameter override
  --densel, --dd LEVEL  drive interface density select on pin 2 (H,L)
  --gen-tg43            generate TG43 signal for 8-inch drive on pin 2 from
                        track 60. Enable postcompensation filter
  --reverse             reverse track data (flippy disk)

DRIVE: Drive (and bus) identifier:
  0 | 1 | 2 | 3       :: Shugart bus unit
  A | B               :: IBM/PC bus unit

SPEED: Track rotation time specified as:
  <N>rpm | <N>ms | <N>us | <N>ns | <N>scp | <N>

TSPEC: Colon-separated list of:
  c=SET               :: Set of cylinders to access
  h=SET               :: Set of heads (sides) to access
  step=[0-9]          :: # physical head steps between cylinders
  hswap               :: Swap physical drive heads
  h[01].off=[+-][0-9] :: Physical cylinder offsets per head
  SET is a comma-separated list of integers and integer ranges
  e.g. 'c=0-7,9-12:h=0-1'

PLLSPEC: Colon-separated list of:
  period=PCT          :: Period adjustment as percentage of phase error
  phase=PCT           :: Phase adjustment as percentage of phase error
  lowpass=USEC        :: Filter flux periods shorter than USEC
  Defaults: period=5:phase=60 (no lowpass filter)
